# React + TypeScript + Vite + TailwindCss + framer motion Landing page

This is a simple landing page created using react-typescript , tailwindcss and framer motion. It has  navbar, Hero, About us, Amenities, Testimonials and a footer components.

## How to run this project on a localsetup

For testing it on a local setup follow these steps:

```
 git init
 git clone https://github.com/mekariyas/Landing-page
 cd Landing-page
 npm install
 npm run dev
```
